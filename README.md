# 灵动玻璃球

原生 Android 设置界面与 OpenGL ES 3.0 悬浮玻璃球。

## 2.0.16 · 构建 26（全屏转场节奏与助手窗口检测优化）

- 全屏隐藏与恢复动画统一调整为约 1100ms，胶囊先轻微放大再舒缓缩小淡出；恢复时从最小尺寸平滑进入并保留轻微回弹。
- 全屏转场期间固定按 120Hz 逐帧提交，不受普通胶囊闲置帧率设置影响。
- 助手联动增加窗口内容变化事件和延迟窗口重查，覆盖部分国产 ROM 先启动助手服务、后挂载界面的时序；仍只读取白名单包名/窗口元数据，不读取文字、不截图、不录音。
- 小米真机复现确认其 `AssistInteractionService` 可被系统绑定，但不一定暴露可供第三方无障碍服务读取的可见窗口；没有增加敏感权限或依赖隐藏系统接口。

## 2.0.15 · 构建 25（全屏转场与收起回弹优化）

- 横屏继续沿用竖屏的顶部位置规则；不让横屏两侧系统 inset 改变胶囊/玻璃球的水平锚点，居中、左侧、右侧和向下展开保持一致。
- 新增默认开启的“全屏时隐藏胶囊”：检测到状态栏隐藏时，自动隐藏胶囊、触控入口和当前非助手悬浮内容；系统语音助手窗口出现时解除隐藏并显示玻璃球。
- 全屏隐藏只改变可见性和输入区域，不停止悬浮服务；状态栏恢复后自动恢复胶囊。
- 全屏隐藏改为独立转场：胶囊先轻微放大，再舒缓缩小并消失；恢复时从最小尺寸弹出，带轻微超出回弹，转场期间不会抢占下层触控。
- 普通快速上滑收起在接近胶囊形态时增加短距离上冲与回弹，位移随收起速度变化，并保留原有的形变与动态内容冻结策略。

## 2.0.13 · 构建 23（系统语音助手窗口适配修复）

- 修复上一版联动没有展开的根因：Android 的 `TYPE_WINDOWS_CHANGED` 只有在服务声明 `flagRetrieveInteractiveWindows` 且允许交互窗口元数据时才会送达；现在通过窗口 ID/根节点包名确认助手窗口，不依赖部分 ROM 上可能为空的事件 `packageName`。
- XML 不再把事件过滤锁死在单一 OPPO 包名，实际判断仍由代码白名单完成，避免系统级窗口事件被 ROM 在分发前过滤。
- 保留数据使用边界：只读取窗口根节点的包名元数据，不读取文字、不截图、不录音、不执行手势、不监听按键；没有新增录音、剪贴板、存储或电池优化豁免权限。由于 Android 官方要求，服务声明了交互窗口内容能力，但代码不读取窗口内容。
- 增加 OPPO、MIUI/HyperOS、小米和 vivo/OriginOS/Funtouch 的助手包名候选；不同系统版本的实际包名可能不同，需在对应真机确认。
- 增加无障碍服务重连及悬浮层晚启动时的当前状态重放，降低助手已出现但玻璃球没有展开的竞态。

## 2.0.12 · 构建 22（OPPO 语音助手联动尝试）

- 仅监听 OPPO `com.heytap.speechassist` 的窗口出现与移除事件；不读取文字、不截图、不录音、不执行手势，也未增加敏感权限。
- 语音助手窗口出现时，当前胶囊自动展开玻璃球；窗口消失后延迟收起。助手仍由系统管理，App 只使用无障碍覆盖层进行视觉覆盖，不能强制结束系统窗口。
- 曾在 OPPO PKB110（Android 16 / ColorOS V16.1.0）观察到助手窗口生命周期变化；上一版用户实测未成功展开，本版针对该事件链路重新修复。

## 2.0.11-r1 · 构建 21（回退版）

- 设置首页重新分类；各级页面统一浅色、深色模块样式。关于与许可集中收纳，不在首页展示详情。
- 二级返回接入 Android 预测性返回的开始、进度、取消和完成回调；首页保留系统返回行为。
- 背景从顶部约 28% 黑色渐变至透明，展开、上滑收起与自动收起继续淡入淡出，并与展开动画同步节奏。
- 新增默认关闭的“向下展开”：胶囊位置保持不变，球体顶部从胶囊底部留出 20 个物理像素后展开。
- 胶囊宽高允许 0，触控入口最小为 38 × 38 dp。倍率滑杆随开关立即启用或禁用，不重建设置页。
- 展开后的输入区域随球体大小及形变更新，球体外不拦截下层内容。保持单层 GL 渲染和固定动画画布。
- 球体暗部强度范围扩展至 0..4，默认值为 2，0 为透明，增强后暗部可达到不透明纯黑；左上滑和右上滑均可收起，并按方向和速度产生不同回弹形变。形变回弹反应默认值为 0.8 秒，收起时保留历史版本的轻微回弹，不额外压缩胶囊。
- 开启“向下展开”后，展开/收起恢复为历史版本的直接胶囊↔玻璃球形变；球体整体向胶囊下方展开，胶囊位置不变。
- 收起过程中冻结波形、圆点和离屏玻璃场景，只保留轻量形状动画，降低卡顿和帧率抖动。
- 使用提供的前景、背景资源作为自适应图标，包含圆形与单色图标入口。

## 安装与权限

安装 dist/灵动玻璃球-2.0.16-全屏转场与助手检测.apk；Android 10 / API 29 及以上、GLES 3.0。
包名 com.cxcboss.glassorb 保持不变，versionName=2.0.16，versionCode=26。

在“运行与权限”中允许悬浮权限；如果需要状态栏区域触控和助手联动，再主动开启“灵动玻璃球触控与助手联动”无障碍服务。首次安装本版后，建议在系统无障碍设置中关闭再重新开启一次该服务，让新的窗口事件配置生效。服务仅读取窗口根节点包名来判断白名单助手，不读取屏幕文字或截图，也不录音、不模拟手势。国产 ROM 如有电池优化或自启动管理，请将本应用设为允许。旧配置保留，新选项缺失时使用默认值。

触控区域使用 WindowManager 输入区域接口；该接口没有公开等价 API，设备不支持时会明确报错并撤下窗口。系统安全界面和不同厂商的悬浮策略仍需以目标设备表现为准。

## 构建与交付

本次仅编译并进行 APK 静态校验，未替用户操作真机；窗口联动、横屏位置、全屏转场、收起回弹、动画观感及小米/vivo 包名命中情况以用户在目标设备上的实际体验为准。

```sh
./gradlew assembleDebug --offline --no-daemon --project-cache-dir /tmp/glass-orb-gradle-project-cache
```

构建目录重定向至 Java 临时目录下的 glass-orb-android-build/app。交付包使用现有 debug 签名，可供本机覆盖安装，不是商店发布签名包。交互、动画及厂商兼容性由用户在设备上确认。
