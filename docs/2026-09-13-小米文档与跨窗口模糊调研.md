# 小米文档与跨窗口模糊调研

日期：2026-09-13

## 小米澎湃 OS 文档

- [全面屏手势提示线适配说明](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1629)：小米将手势提示线与虚拟按键视为同一窗口，并说明沉浸式状态栏/虚拟键需要让内容延伸到系统栏区域；如果页面不希望被遮挡，才使用 `fitsSystemWindows`。本项目的悬浮层需要覆盖状态栏区域，因此视觉坐标不能把状态栏 inset 当作顶部最小值；窗口继续使用 `FLAG_LAYOUT_IN_SCREEN`、`FLAG_LAYOUT_NO_LIMITS`、关闭 fit insets 和允许 cutout 的组合。

- [公平运行内存适配](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2304)：小米以 PSS 作为物理内存指标，明确不应在 UI 线程、定时器或 `onDraw` 中高频调用内存统计 API；应用应监听 `itgsa.intent.action.TRIM`，在内存预警/查杀信号后尽快释放可释放资源，并在 3 秒内通过 `common.callback` Binder 回报处理结果。本项目没有图片缓存、WebView 或无界 Java 缓存，因此只暂停闲置的 submit-driven GLES 工作，并加入容错的动态接收器与 Binder 回执，不主动采集 PSS。

## Android 跨窗口模糊

- Android 12（API 31）提供 `Window.setBackgroundBlurRadius()` 和 `WindowManager.LayoutParams.setBlurBehindRadius()`；前者只在窗口范围内模糊，后者会模糊窗口后方内容。两者都受 `WindowManager.isCrossWindowBlurEnabled` 控制，并可能因 GPU 能力、省电模式、视频播放或系统策略动态关闭。
- 官方建议监听 `addCrossWindowBlurEnabledListener`，在不支持时使用无模糊的备用外观。AOSP 还提示跨窗口模糊是昂贵操作，背景模糊半径通常不应超过 150 px。本项目仍使用小半径、默认关闭，并在能力不可用时完全撤掉可选层。
- `RenderEffect` 只适合模糊同一窗口自身内容，不能稳定地实时采样其他 App 的下层窗口；因此本项目保留系统 compositor 的跨窗口背景模糊路线。

## 本次实现约束

1. 竖屏参考坐标的顶部恢复为 0，允许胶囊位置进入状态栏区域；导航区域仍保留边缘约束。
2. 背景模糊层使用稳定的玻璃球触控边界，不再把呼吸、形变和 GLES 每帧边界传给 WindowManager；窗口只在展开/收起、配置、旋转或系统能力变化时增删或更新。
3. 模糊层仍只在 Android 12+、系统能力开启、玻璃球为圆形且可见时工作；椭圆、隐藏、能力关闭时保留原有玻璃球，不让可选功能影响主渲染。
