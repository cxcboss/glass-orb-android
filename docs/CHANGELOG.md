# 更新日志

## 2.0.29（versionCode 39）

### 设置页重做：复刻 iOS 26“设置” + 液态玻璃
- 按 iOS 26“设置”重建结构：根页大标题“设置”、应用资料卡、彩色图标分组列表（无副标题，开关与状态值直接在列表中），取消了原先的“常用 / 详细”底部标签栏。
- iOS 26 底部玻璃搜索框：可搜到每一项设置（中英文），点结果直接跳到对应页面并滚动到该项。
- 二级页使用“图标 + 标题 + 说明”头卡，标题滚走后才出现在导航栏；导航栏改为无分隔线的“滚动边缘”渐隐材质，返回键为圆形玻璃按钮。
- 滑杆行去掉“还原”按钮：数值偏离默认时变蓝，长按该行弹出玻璃上下文菜单恢复默认值。
- 确认框改为 iOS 26 样式：左对齐文字、胶囊按钮。纯色分组背景，去掉 Toast。
- 液态玻璃三档：API 33+ 带 AGSL 边缘镜头，31–32 为模糊，29–30 自动降级为半透明纯色。
- 新增“开机自动启动”开关（此前后端已实现但没有入口）与“开源许可与声明”页。
- 移除 Material 依赖：APK 由 17.7 MB 降到约 10.4 MB。

### 缺陷修复
- 设置滑杆最后一次拖动可能因 ViewModel 被销毁而没落盘：防抖落盘改由仓库的进程级协程负责。
- 配置仓库 `publishGeneration` 非原子，且 DataStore 迟到的旧值可能覆盖实时配置：改为原子计数，DataStore 仅启动读取一次。
- `OverlayWindowController.show()` 在窗口已发布后失败会残留半构建状态：统一走 `removeView()` 清理。
- 服务对 `APP_APPEARANCE` / `TOUCH_PREVIEW` 也重发前台通知，且可能为这类命令留下空通知：改为仅对启动/显示/隐藏命令进入前台。
- 通知与 Toast 文案硬编码中文：改为中英文字符串资源。
- 英文界面缺“灵动岛宽度/高度”翻译；`SettingsRefreshRateController.dispose()` 从未被调用；过期的设备测试引用了不存在的 JSON 导入界面。

### 性能
- 下层模糊控制器每帧分配 `List<IntRect>`×5：改为输入未变化时提前返回，空闲帧零分配。
- 玻璃球模糊关闭时，每帧仍计算光圈与请求对象：改为开关关闭直接 `hide()`。
- 下层模糊窗口创建失败后不再每帧重试（既浪费，也会把窗口插到 GL 之上）。
- 显示几何（Android 11+ 的 WindowMetrics 查询）改为短时缓存；旋转、显示或配置变化后 1.5 秒内仍逐帧读取，保证旋转跟手。
- GL 错误检查从每帧同步改为前两帧 + 每 120 帧一次，去掉每帧的驱动同步点。
- 设置页玻璃只在与失效区域重叠时重新捕获，拖动中部滑杆不再逐帧重新模糊顶部/底部玻璃。
- 以上优化都不改变帧率：活跃动画仍每个 VSync 提交并请求 120 Hz。

### 文档与仓库整理
- 新增 `docs/HANDOFF.md`（对接文档）、`SETTINGS_UI.md`、`AUDIT.md`、`CHANGELOG.md`；`AI_HANDOFF.md` 并入 `HANDOFF.md`。
- 清理 `.DS_Store`、`.omx/` 工具状态、`dist/` 里的 APK 压缩副本；补全 `.gitignore`；推广研究文档移到 `docs/research/`。
- 更新应用内与仓库内的许可声明，使其与“无 Material、玻璃为独立实现”一致。
